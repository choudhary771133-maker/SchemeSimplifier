# SchemeSimplifier – Samjho, Apply Karo

## Purpose
SchemeSimplifier is a student-friendly web prototype that simplifies government schemes, scholarships and educational opportunities by showing possible eligibility, documents, deadlines, steps and official sources in one place.

## Features
- Student profile input
- Rule-based opportunity matching
- Eligibility guidance
- Required-document checklist
- Deadline guidance
- Step-by-step application flow
- Official-source links
- Responsive mobile-friendly interface

## Technology
- HTML5
- CSS3
- Vanilla JavaScript
- JavaScript array used as prototype sample data

## Setup
1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in a modern web browser.
4. Enter a sample student profile and click **Check My Opportunities**.

No build tools or installation are required.

## Sample Data
The prototype contains clearly labelled sample opportunity data. Details such as eligibility and deadlines must be verified on the linked official source before real-world use.

## Testing
Test at least these cases:
- Age 18, undergraduate, Rajasthan → matching opportunities should appear.
- Age 18, 12th, Rajasthan → national/educational sample opportunities should appear.
- Change state or education → results should change.
- Click an official-source button → the linked official website should open in a new tab.
- Test on both desktop and mobile screen sizes.
